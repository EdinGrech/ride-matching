# Shared Authentication

Internal Angular library for the OIDC `AuthFacade`, authentication interceptor, and configuration types used by both applications.

Run commands from `ride-matching-angular` after `npm ci`:

```powershell
npx ng build shared-auth
npm run test -- shared-auth --watch=false
```

This library is private to this repository and is not published to npm. See the [Angular application guide](../../README.md) for application setup.
