# Shared Map

Internal Angular library for the Leaflet ride map. It exports `RideMapComponent`, `MapLocation`, and `MapMarker` for the passenger and driver applications.

Run commands from `ride-matching-angular` after `npm ci`:

```powershell
npx ng build shared-map
npm run test -- shared-map --watch=false
```

This library is private to this repository and is not published to npm. See the [Angular application guide](../../README.md) for application setup.
